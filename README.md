# 譜読みMIDI

楽譜(PDF・画像)を段ごとに切り分けてClaudeで読み取り、MIDIに変換するWebツールです。読み取った結果はブラウザ上でピアノロール表示・プレビュー再生できます。

## 使い方

1. 「ファイルを選ぶ」から楽譜のPDFか画像を選ぶ(複数可)
2. Anthropic APIキーを入力する(初回のみ。ブラウザに保存されます)
3. 「読み取り開始」を押す
4. プレビューで確認し、「MIDIを保存」で `.mid` をダウンロード

## 公開方法(GitHub Pages)

`index.html` をリポジトリの直下に置き、Settings → Pages で `main` ブランチ / `/(root)` を選ぶと公開されます。

## 注意

- 読み取りには Anthropic API(画像入力)を使い、料金はAPIキーのアカウントにかかります。
- APIキーは使っているブラウザの localStorage にだけ保存されます。共有の端末では使わないでください。
- 斜めに撮った写真や手書きの楽譜は読み取り精度が落ちます。
